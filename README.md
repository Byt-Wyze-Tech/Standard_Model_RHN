# Standard Model with Right-Handed Dirac Neutrinos

This publication provides a complete written form of the Standard Model extended by three right-handed neutrinos.

The added neutrinos allow neutrinos to have Dirac masses in the same general way that the other matter particles acquire mass. Majorana mass terms are not included.

The model is written after electroweak symmetry breaking, using the physical photon, Z boson, W bosons, Higgs field, quarks, charged leptons, and neutrinos. It uses the 't Hooft-Feynman gauge.

## Contents

The model includes:

- Strong, weak, and electromagnetic interactions
- Higgs interactions
- Quark and lepton mass terms
- Three generations of quarks and leptons
- Quark mixing through the CKM matrix
- Neutrino mixing through the PMNS matrix
- Three right-handed neutrinos
- Dirac neutrino masses
- Goldstone fields
- Gauge-fixing terms
- Faddeev-Popov ghost terms
